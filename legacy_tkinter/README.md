# Архив старого интерфейса

Здесь сохранены прежние `main.py`, `ui_helpers.py` и `test_ui.py` перед переходом на HTML/CSS + pywebview.

Новый `start.bat` эти файлы не использует. Это архив исходников, а не отдельная поддерживаемая сборка: старые тесты и импорты требуют прежней структуры и `customtkinter`.

Актуальный интерфейс находится в `../web/`, запуск — через `../main.py` или `../start.bat`.
