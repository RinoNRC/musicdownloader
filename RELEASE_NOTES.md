# Music Drive v1.0.0

Первый готовый Windows-релиз приложения для поиска музыки и сохранения MP3 на компьютер или USB-накопитель.

## Скачать и запустить

1. Скачайте **MusicDrive-1.0.0-windows-x64.zip** из раздела Assets ниже.
2. Распакуйте **весь архив**, затем запустите **MusicDrive.exe**.
3. Python устанавливать не нужно. Не удаляйте `MusicDriveWorker.exe` и папку `_internal`.

**Требования:** Windows 10/11 x64, доступ к интернету и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (обычно уже есть в Windows).

**FFmpeg не включён в ZIP.** При первом скачивании приложение запросит разрешение загрузить около 30 МБ напрямую с PyPI. Проверяются SHA-256 пакета и исполняемого файла; инструмент сохраняется в `%LOCALAPPDATA%\MusicDownloader\tools`. Это стороннее ПО под GPLv3+. При отказе поиск остаётся доступен. Также можно указать существующий FFmpeg через переменную среды `IMAGEIO_FFMPEG_EXE`.

## Возможности

- Поиск по названию на YouTube и SoundCloud, прямые ссылки на отдельные треки.
- Общая подборка из нескольких поисковых запросов, пакетная загрузка и остановка.
- MP3 CBR: 128 / 192 / 256 / 320 кбит/с; по умолчанию 192 кбит/с, стерео 44,1 кГц, ID3v2.3.
- Сохранение на USB, транслитерация русских имён файлов, защита от перезаписи готовых файлов.
- Современный интерфейс на WebView2, настройки, прогресс и журнал ошибок.

## Проверки

- 59 автоматических тестов.
- Запуск собранного EXE в WebView2, работа UI и отдельного загрузчика.
- Установка FFmpeg с PyPI и полное преобразование локального тестового WAV в MP3 с ID3v2.3.

Сборка проверена на текущем Windows-компьютере разработчика; отдельная проверка на чистой Windows 10 не выполнялась.

## Важно

- Сборка **не подписана** сертификатом. Windows SmartScreen может показать предупреждение. Проверяйте репозиторий и SHA-256 из `SHA256SUMS.txt`; не отключайте защиту Windows.
- Некоторым видео YouTube нужен **Deno** (`winget install --id DenoLand.Deno -e`). Наличие runtime не гарантирует доступность любого видео.
- Плейлисты и DRM не поддерживаются. Ограничения площадок, региона или авторизации могут мешать загрузке.
- Скачивайте только материалы, на которые у вас есть права или разрешение.
- Для обновления распакуйте следующую версию в новую папку. Настройки сохраняются в `%LOCALAPPDATA%\MusicDownloader\settings.json`.

Сторонние лицензии и сведения о компонентах включены в ZIP (`THIRD_PARTY_NOTICES.md`, `licenses/`).
