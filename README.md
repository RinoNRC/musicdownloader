# MusicDownloader

Приложение для поиска музыки на YouTube и SoundCloud и сохранения выбранных треков в MP3, в том числе на USB-накопитель. Современный интерфейс написан на **HTML/CSS/JavaScript**, открывается в отдельном окне через **pywebview + Microsoft Edge WebView2** и не использует Tkinter. Поиск и скачивание работают на Python через **yt-dlp**, без платных API. Node.js и сборка фронтенда для запуска не нужны.

## Возможности

- Поиск на YouTube и SoundCloud или ввод прямой ссылки на отдельный трек/видео.
- Общая «Подборка»: добавляйте треки из разных поисковых запросов и скачивайте их одной кнопкой.
- Выбранные результаты подсвечиваются; повторный поиск не сбрасывает выбор. Можно удалить отдельный трек или очистить весь список.
- После успешного скачивания трек удаляется из списка; ошибочные и ещё не скачанные остаются для повторной попытки. Список хранится до закрытия приложения.
- Качество MP3: **128, 192, 256 или 320 кбит/с**; по умолчанию — **192 кбит/с**.
- Постоянный битрейт (CBR), стерео, частота дискретизации **44 100 Гц**, теги **ID3v2.3**.
- Опция ASCII/транслитерации имен файлов для устройств, которые плохо поддерживают кириллицу.
- Выбор папки назначения, включая папку на USB-накопителе.
- Плейлисты не поддерживаются: используйте ссылки на отдельные треки или видео.

Повышение битрейта не восстанавливает качество, отсутствующее в исходной записи.

## Готовая версия для Windows (без Python)

Скачайте **`MusicDrive-1.0.0-windows-x64.zip`** на странице [GitHub Releases](https://github.com/RinoNRC/musicdownloader/releases/latest).

1. Распакуйте **весь архив** в отдельную папку. Не запускайте EXE прямо из ZIP.
2. Запустите **`MusicDrive.exe`**. Соседние `MusicDriveWorker.exe` и папка `_internal` нужны для работы — не удаляйте их.
3. При первом скачивании разрешите установку FFmpeg: приложение загрузит около **30 МБ напрямую с PyPI**, проверит SHA-256 и сохранит инструмент в `%LOCALAPPDATA%\MusicDownloader\tools`. FFmpeg не включён в ZIP и распространяется его поставщиком под GPLv3+. При отказе поиск продолжает работать.

Нужны **Windows 10/11 x64** и **Microsoft Edge WebView2 Runtime**. Установка Python, pip и ручная настройка FFmpeg не требуются. Вместо загрузки FFmpeg можно указать путь к уже установленному EXE через переменную среды `IMAGEIO_FFMPEG_EXE` перед запуском.

Сборка не подписана цифровым сертификатом: Windows может показать предупреждение SmartScreen. Проверяйте адрес репозитория и контрольную сумму из `SHA256SUMS.txt`; не отключайте антивирус. Проверка ниже подтверждает целостность, а не подпись издателя:

```powershell
Get-FileHash .\MusicDrive-1.0.0-windows-x64.zip -Algorithm SHA256
```

Для обновления закройте приложение и распакуйте новый релиз в новую папку. Пользовательские настройки и загруженный FFmpeg сохраняются отдельно. `update.bat` относится только к запуску из исходников.

## Требования для запуска из исходников

- Windows и **Python 3.10 или новее**, установленный с добавлением в PATH, либо доступный через `py -3`.
- Подключение к интернету для установки зависимостей, поиска и загрузки.
- **Microsoft Edge WebView2 Runtime** (обычно уже установлен в Windows 10/11). Если окно не открывается, установите Evergreen Runtime с [официального сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/), затем повторите запуск.
- Зависимости из `requirements.txt`: `pywebview`, `yt-dlp[default]`, `imageio-ffmpeg`.

При запуске из исходников `imageio-ffmpeg` поставляет FFmpeg: **отдельно устанавливать его не нужно**. Python нужен только для исходников, но не для готового ZIP-релиза.

## Первый запуск

1. Установите Python 3.10 или новее. В установщике Windows включите **Add Python to PATH**.
2. Откройте папку проекта и запустите **`start.bat`**.
3. При первом запуске скрипт создаст локальное виртуальное окружение `.venv` и установит зависимости из `requirements.txt`.
4. После успешной установки появится служебный файл `.venv\.installed`, затем запустится `main.py`.

При последующих запусках используйте тот же `start.bat`: он сравнивает `requirements.txt` с маркером и устанавливает зависимости только при их изменении или отсутствии маркера. Поэтому переход со старой версии на новый интерфейс не требует ручной установки библиотек. Если установка завершилась ошибкой, маркер не обновляется и следующий запуск повторит установку. При ошибке окно останется открытым — прочитайте сообщение перед закрытием.

Если каталог `.venv` существует, но окружение повреждено или в нем отсутствует интерпретатор, переименуйте либо удалите **только `.venv`** и снова запустите `start.bat`.

### YouTube и JavaScript runtime

Для некоторых видео YouTube библиотеке yt-dlp может потребоваться внешний JavaScript runtime. Рекомендуется **Deno**. Установите его в терминале:

```powershell
winget install --id DenoLand.Deno -e
```

После установки перезапустите приложение. Если запускали его из терминала, закройте и заново откройте терминал, чтобы обновился PATH. Приложение автоматически обнаруживает доступные **Deno или Node.js**. Наличие runtime не гарантирует доступность любого видео.

## Как пользоваться

1. Введите поисковый запрос для YouTube или SoundCloud либо прямую ссылку на отдельный трек/видео. Название можно вставить через Ctrl+V в любой раскладке или через правую кнопку мыши → «Вставить».
2. Нажмите «+» рядом с нужным результатом: он подсветится, «+» сменится галочкой, а трек появится справа в «Подборке».
3. Введите название следующей песни и снова нажмите «Найти». Предыдущий выбор сохранится. Повторяйте, пока не соберёте нужные треки.
4. При необходимости удалите лишние треки кнопкой «×» справа. «Выбрать все» / «Снять выбор» действует только на текущие результаты, а значок корзины очищает всю подборку после подтверждения.
5. Откройте «Настройки»: выберите битрейт (по умолчанию 192 кбит/с), папку назначения, например на USB-накопителе, и при необходимости включите имена файлов латиницей. Сохраните настройки.
6. Нажмите «Скачать подборку»: приложение последовательно скачает весь собранный список, а не только текущие результаты поиска. Успешно сохранённые треки исчезнут из списка; остальные останутся.
7. Дождитесь завершения записи файлов. Перед извлечением USB используйте безопасное извлечение Windows.

Папка загрузки по умолчанию: **`~/Music/MusicDownloader`**, где `~` — домашний каталог пользователя.

Настройки сохраняются локально в **`%LOCALAPPDATA%\MusicDownloader\settings.json`**.

## Обновление

Закройте приложение и запустите **`update.bat`**. Скрипт обновит pip и зависимости из `requirements.txt` с флагом `--upgrade`. Маркер `.venv\.installed` создается заново только после успешного завершения; при ошибке он не записывается. В конце окно ожидает нажатия клавиши.

Если виртуальное окружение еще не создано, сначала запустите `start.bat`.

## Ручной запуск

В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Если команда `python` недоступна, для создания окружения используйте `py -3 -m venv .venv`. Активация окружения не обязательна: команды выше обращаются к его интерпретатору напрямую.

## Тесты

Из папки проекта, с установленными зависимостями:

```powershell
python -m unittest discover -s tests -v
```

Чтобы явно использовать локальное окружение без активации:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Интеграционная проверка настоящего окна WebView2 (открывает и закрывает тестовое окно; не скачивает музыку из интернета и не меняет пользовательские настройки):

```powershell
.\.venv\Scripts\python.exe tests\webview_smoke.py
```

## Сборка Windows-релиза

На Windows x64 с Python 3.11 и созданным `.venv` запустите **`build.bat`**. Он устанавливает зависимости сборки, запускает тесты, собирает два EXE через PyInstaller, собирает лицензии и создаёт ZIP с SHA-256 в `dist`. Для повторения набора версий первого релиза используйте `requirements-release.txt`.

Ручные команды:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-release.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean MusicDrive.spec
.\.venv\Scripts\python.exe scripts\collect_licenses.py
.\.venv\Scripts\python.exe scripts\package_release.py
```

Проверка именно собранного приложения (откроет тестовое окно, скачает FFmpeg с PyPI во временную папку и преобразует локальный тестовый WAV; музыку из интернета и пользовательские настройки не затрагивает):

```powershell
Start-Process -Wait .\dist\MusicDrive\MusicDrive.exe -ArgumentList '--self-test', 'C:\Temp\musicdrive-report.json'
Get-Content C:\Temp\musicdrive-report.json
```

FFmpeg, Unidecode и Mutagen исключены из бинарной сборки. Не добавляйте их в архив вручную; сведения о сторонних компонентах находятся в `THIRD_PARTY_NOTICES.md` и `licenses`.

## Структура

- `main.py` — запуск отдельного окна WebView2.
- `desktop_api.py` — потокобезопасный Python API для интерфейса, очередь, настройки и прогресс.
- `web/index.html`, `web/styles.css`, `web/app.js` — интерфейс без внешних CDN и сборщиков.
- `music_core.py`, `download_worker.py` — поиск, скачивание и преобразование MP3.
- `tests/` — тесты загрузчика и нового API без необходимости открывать окно.
- `legacy_tkinter/` — сохранённый исходный интерфейс и его старые тесты для справки; новый запуск их не использует.

Не открывайте `web/index.html` напрямую для скачивания: Python-функции подключаются только при запуске через `start.bat`. В интерфейсе нет воспроизведения музыки: нижняя панель показывает именно загрузку и конвертацию.
